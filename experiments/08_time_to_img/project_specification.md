Motivation & Learning ObjectivesThis project transforms 1D financial time-series data into 2D image representations to frame market regime prediction as a traditional computer vision classification task.Students will:Encode windowed log-returns using Gramian Angular Fields (GAF), Continuous Wavelet Transforms (CWT), and Short-Time Fourier Transforms (STFT).Train lightweight CNNs or Vision Transformers (ViT) on these visual representations.Contrast how different transforms capture temporal dependencies versus frequency/volatility clustering.2. Approach & Dataset DesignInstead of predicting the unpredictable (next-bar direction), the pipeline classifies statistically defined market regimes using sliding windows of asset log-returns.FeatureSpecificationInput Datayfinance log-returns (e.g., S&P 500, EURUSD) to ensure stationarityWindow Size128 trading periods (with a step size of 16 for dataset generation)Image Size128×128 or 224×224 (for ResNet/ViT compatibility)EncodingsGAF (pyts), CWT Scalogram (PyWavelets), STFT Spectrogram (scipy.signal)Target Classes1: Low-Vol Bull, 2: Low-Vol Bear, 3: High-Vol / Choppy, 4: Volatility ShockLabel SourceProgrammatic historical volatility and directional trend metrics3. Pipeline StagesAcquisition & Preprocessing: Compute rolling log-returns. Identify and label 128-bar windows into one of the four regime classes based on realized variance and moving average slopes.Transform Tournament: Generate three distinct datasets from the exact same windows. Convert 1D arrays into 2D RGB arrays using continuous colormaps (e.g., viridis).Training: Train a shared base architecture (e.g., ResNet-18) independently on the GAF, CWT, and STFT datasets.Evaluation: Compare validation accuracy across the three transforms.5. Honest Limitations & Discussion PointsThe Cone of Influence (COI): Wavelet transforms suffer from edge artifacts at the boundaries of the time window. Students must learn to recognize these as mathematical byproducts, not financial signals.Look-ahead Bias: If regime labels are calculated using centered rolling windows (incorporating future data), the model learns to predict the labeler's future knowledge. Targets must be strictly backward-looking.Information Density: GAF preserves exact temporal ordering but struggles with noisy, non-stationary data. Scalograms excel at highlighting volatility clustering but abstract away raw price levels.
